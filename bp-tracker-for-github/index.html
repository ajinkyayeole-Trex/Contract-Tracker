    Add contract

    Type the details from Salesforce, or attach the contract PDF below to fill them in. For each line, fill in any two of RT kms, MinG and RT amount and the third is worked out (RT amount = MinG × RT kms).

    Paste several lines at once

    One line per row: line code, RT kms, MinG, RT amount. Leave one empty and it's worked out. Copying cells straight from Excel or Salesforce works.

    Attach contract PDF (optional)Attach the Lines Annex / Vehicles Annex or the DocuSign PDF and the form fills in by itself. Leave it empty to enter everything by hand. The PDF is read on your computer and not uploaded anywhere.

    🔑 Editor sign-in

    Editors can add and change BPs for the whole team. You need a GitHub account that has added to the project , and a GitHub token. You only do this once on each computer.

    How do I get a token?
    1. Sign in to github.com. Accept the invite to the project if you haven't yet (check your email).
    2. Click your photo (top right) → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Tokens (classic).
    3. Click Generate new token → Generate new token (classic).
    4. Note: “BP tracker”. Expiration: 90 days. Tick only public_repo.
    5. Click Generate token, copy it (starts with ghp_) and paste it above.

    The token stays on this computer only. When it expires, make a new one and sign in again.
